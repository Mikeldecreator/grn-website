# God's Royal Nation (GRN) Website

This repository contains the source code for the official website of God's Royal Nation (GRN), a vibrant Christian community dedicated to faith, unity, and service.

## About The Project

The GRN website serves as the digital home for the God's Royal Nation community, built to reflect its mission of spreading the gospel and connecting with members. The design and structure are inspired by the organization's identity and values.

Key features of the website include:
*   **Informational Pages:** Detailed sections for 'About Us', 'Our Vision & Mission', and service times.
*   **Branch Locations:** Information on the various GRN branches.
*   **Contact Information:** Easy access for inquiries and communication.

### Built With

This project is built with modern web technologies to ensure a fast, responsive, and reliable experience.

*   [Next.js](https://nextjs.org/)
*   [React](https://reactjs.org/)
*   [TypeScript](https://www.typescriptlang.org/)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have pnpm installed. If not, you can install it via npm:
```sh
npm install -g pnpm
```

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/your_username_/your_project_name.git
    ```
2.  Install packages
    ```sh
    pnpm install
    ```

### Running the Application

To run the development server:
```sh
pnpm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
